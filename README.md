# Qehwa Chess

React + TypeScript + Vite + Tailwind app on a Supabase backend: tournaments, clubs, cities, meetups, messaging, players.

## Setup
1. `npm ci`
2. Copy `.env.example` to `.env` and fill in your Supabase URL and anon key.
3. Apply `supabase/migrations/*.sql` in filename order (SQL editor or `supabase db push`).
4. `npm run dev`

## Scripts
`npm run dev` · `npm run build` · `npm run lint`
